# CareerPilot DSA Implementation


## 1. HashMap - Application Status Counter

Purpose:
Used to calculate application statistics.

Usage:
Counts Applied, Interview, Offer and Rejected applications.

Complexity:
Time: O(n)
Space: O(k)


## 2. Sorting - Deadline Sorter

Purpose:
Sort applications based on deadlines.

Usage:
Helps users prioritize upcoming deadlines.

Complexity:
Time: O(n log n)
Space: O(1)
